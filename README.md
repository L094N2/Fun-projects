# Low Poly Co-op Heist Game

Deploy-ready multiplayer browser game inspired by One-Armed Robber.

## Features
- Low poly visuals
- Cross-platform desktop/mobile
- Three.js 3d world
- Multiplayer-ready architecture
- Vercel deployment support

## Setup

```bash
npm install
npm run dev
```

## Deploy
Deploy to Vercel using the "Other" framework preset.

## Notes
TypeScript and Next.js dependencies are now configured for Vercel builds.
